# Profile README Setup & Customization Guide

An Apple-inspired, minimalist, and self-contained GitHub Profile README engineered for performance, aesthetic cohesion, and zero external downtime.

---

## Overview & Architecture

Unlike typical developer profile templates that rely on third-party Vercel or Heroku services (which frequently suffer from rate limits and `503 DEPLOYMENT_PAUSED` outages), this repository is **100% self-contained**:

- **Native SVGs with CSS Keyframe Animations**: Pure CSS animations (`@keyframes`) that execute natively within GitHub's sanitized image proxy (`camo.githubusercontent.com`).
- **Dynamic Stickman & Gravestones Contribution Graph**: A custom SVG generator script queries your real GitHub contributions via GraphQL and renders an animated stickman firing a glowing laser projectile across the grid, with miniature tombstone silhouettes on zero-contribution days.
- **Self-Contained Stats & Language Meter**: Automatically aggregates your repository statistics and language breakdown into a local, curated SVG card (`assets/github/stats.svg`).
- **System Typography & Cohesive Palette**: Styled with a dark glass luxury aesthetic (`#0e0e0e` canvas, `#b76e79` rose-gold, `#c9a87c` gold accent, and Apple system typography).

## Step-by-Step Setup for Your Profile

Follow these steps to replicate or adapt this profile README for your own GitHub account:

### Step 1: Create Your Special Profile Repository

GitHub only displays a profile README if the repository name matches your GitHub username exactly:

1. Go to [github.com/new](https://github.com/new).
2. Enter your **exact GitHub username** as the **Repository name** (e.g., if your username is `octocat`, name the repository `octocat`).
3. Make sure the repository visibility is set to **Public**.
4. Initialize with or without a README (we will push this repository's contents).

### Step 2: Clone or Copy the Repository Files

Clone this repository to your local machine:

```bash
git clone https://github.com/swastik-chavan/swastik-chavan.git my-profile
cd my-profile
```

Reset the remote origin to your own repository:

```bash
git remote set-url origin https://github.com/<YOUR-USERNAME>/<YOUR-USERNAME>.git
```

### Step 3: Personalize Your Details

Perform a quick search and replace across the repository to swap in your details:

| File | What to update |
|------|----------------|
| `README.md` | Replace `swastik-chavan` with your GitHub username in all links. Update bio text, social links, email, and the Selected Work table. |
| `assets/hero/hero.svg` | Edit lines with `<text>` to update your name, tagline, and role. |
| `assets/hero/hero-alt.svg` | Edit lines with `<text>` if you plan to use the typing-cursor hero variant. |
| `scripts/generate-contributions.js` | Update `GITHUB_USER = process.env.GITHUB_USER || 'your-username'`. |
| `.github/workflows/update-profile.yml` | Update `GITHUB_USER: your-username`. |

## Step 4: Configure Automation (Personal Access Token)

The custom contribution graph and stats card use GitHub's GraphQL API to read your activity calendar.

### 1. Create a GitHub Personal Access Token (Classic)

1. Navigate to [GitHub Settings > Personal Access Tokens (Classic)](https://github.com/settings/tokens).
2. Click **Generate new token > Generate new token (classic)**.
3. Give it a descriptive note (e.g., `Profile README Generator`).
4. Set an expiration period (e.g., 90 days, 1 year, or No expiration).
5. **Under Select Scopes, check ONLY:**
   - `[x] read:user` *(Read all user profile data)*
   *(Do NOT select repo, admin, or write permissions. This token strictly needs read-only access to your public profile calendar).*
6. Click **Generate token** and copy the token string (`ghp_...`).

### 2. Add the Secret to Your Repository

1. Go to your repository on GitHub: `https://github.com/<YOUR-USERNAME>/<YOUR-USERNAME>`.
2. Click **Settings** (top tab).
3. In the left sidebar, navigate to **Secrets and variables > Actions**.
4. Click the green **New repository secret** button.
5. Fill in the fields:
   - **Name**: `GH_TOKEN`
   - **Secret**: *(Paste your copied PAT)*
6. Click **Add secret**.

### 3. Ensure Workflow Permissions Are Enabled

GitHub Actions needs write permission to commit updated SVG files back to your repository:

1. In repository **Settings**, navigate to **Actions > General** in the left sidebar.
2. Scroll down to **Workflow permissions**.
3. Select **Read and write permissions**.
4. Check **Allow GitHub Actions to create and approve pull requests**.
5. Click **Save**.

### 4. Trigger the First Build

1. In your repository, click the **Actions** tab.
2. Under **All workflows**, click **Update Profile Assets**.
3. Click the **Run workflow** dropdown button on the right, and click the green **Run workflow** button.
4. Once completed (approx. 15–30 seconds), the action will commit your real contribution graph and stats card directly to `assets/github/`.

## Running Locally

You can also generate the assets on your local workstation without waiting for GitHub Actions:

### Linux / macOS (Bash / Zsh):

```bash
export GITHUB_TOKEN="ghp_your_token_here"
export GITHUB_USER="your-username"
node scripts/generate-contributions.js
```

### Windows (PowerShell):

```powershell
$env:GITHUB_TOKEN="ghp_your_token_here"
$env:GITHUB_USER="your-username"
node scripts/generate-contributions.js
```

Both `assets/github/contributions.svg` and `assets/github/stats.svg` will be regenerated immediately.

## Customization Guide

### 1. Switching Hero Banners

Two distinct hero styles are included:

1. **Floating Shapes Hero (`assets/hero/hero.svg`)**: Minimalist geometry with subtle, asynchronous floating animations and a rose-gold underline.
2. **Terminal Cursor Hero (`assets/hero/hero-alt.svg`)**: Monospace-accented header featuring an animated blinking typing cursor.

To switch to the alternative hero, open `README.md` and swap the active image:

```html
<!-- Primary Hero (Default): -->
<!-- <p align="center"><img src="./assets/hero/hero.svg" alt="Hero" width="720"/></p> -->

<!-- Alternative Hero: -->
<p align="center">
  <img src="./assets/hero/hero-alt.svg" alt="Hero Alt" width="720"/>
</p>
```

### 2. Changing the Accent Color Palette

All assets share a cohesive palette. You can search and replace hex codes across all `.svg` files to re-theme the design:

| Element | Default Color | Purpose |
|---------|---------------|---------|
| Canvas Background | `#0e0e0e` | Deep neutral OLED black |
| Card Surface | `#141414` / `#161616` | Subtle contrast card fill |
| Primary Accent | `#b76e79` | Metallic rose-gold |
| Secondary Accent | `#c9a87c` | Warm gold highlight |
| Primary Text | `#f0f6fc` / `#e0e0e0` | Clean high-contrast typography |
| Secondary Text | `#777777` / `#888888` | Muted metadata and labels |
| Structural Borders | `#1f1f1f` / `#222222` | Ultra-subtle border stroke |

### 3. Custom Project Cards

The showcase cards (`openorg.svg` and `techx.svg`) are standard SVGs rendered at calibrated widths:

- **Large Project Card**: `viewBox="0 0 600 130"` rendered at `width="520"` in `README.md`.
- **Compact Brand / Channel Card**: `viewBox="0 0 600 90"` rendered at `width="440"` in `README.md`.

To create your own cards, copy `assets/openorg/openorg.svg` or `assets/techx/techx.svg` and update the title, badge, and description text while preserving the gradients and border styling.

### 4. Adding Tech Stack Icons

Icons in the **tech stack** section are sourced from [Devicon](https://devicon.dev/) (56×56 resolution) and [SimpleIcons](https://simpleicons.org/):

```html
<img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/kotlin/kotlin-original.svg" alt="Kotlin" width="56" height="56"/>
```

> **Dark Mode Tip**: Default icons with dark fills (such as GitHub's standard black logo) will disappear against GitHub's dark theme. For dark logos, use local white SVGs (like `./assets/icons/github.svg`) or SimpleIcons with a white fill (`https://cdn.simpleicons.org/github/white`).

## Technical Insights & GitHub Quirks

1. **GitHub Camo Proxy & Caching**:
   GitHub proxies all markdown images through `camo.githubusercontent.com` and caches them aggressively. When you push an SVG update or when the daily Action runs, it may take 5–10 minutes for GitHub's cache to refresh. To see changes immediately on your machine, perform a hard refresh (`Ctrl + F5` or `Cmd + Shift + R`).
2. **SVG Image Constraints**:
   When SVGs are embedded via `<img>` tags in Markdown:
   - Pure CSS `@keyframes` and inline `<style>` animations **work**.
   - Embedded `<script>` tags and JavaScript are **completely blocked** by GitHub for security.
   - External web fonts (`@import url('https://fonts...')`) are **stripped**. All SVGs in this repository use system fallback stacks (`-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`) to ensure consistent, native rendering on all operating systems.

## Troubleshooting

| Problem | Cause | Resolution |
|---------|-------|------------|
| README does not appear on profile | Repository name does not match username | Rename the repository to match your exact GitHub username (case-insensitive) and ensure visibility is **Public**. |
| GitHub Action fails with `GraphQL error` | Invalid or missing `GH_TOKEN` secret | Verify the PAT was generated with `read:user` and that the secret name in repo settings is exactly `GH_TOKEN`. |
| GitHub Action fails with `403 Permission denied to github-actions[bot]` | Missing workflow write permissions | In repo **Settings > Actions > General > Workflow permissions**, select **Read and write permissions**. |
| Broken image icons for external stats | Third-party Vercel server downtime | This repository replaces external stats with the local `assets/github/stats.svg`. Make sure your README references `./assets/github/stats.svg`. |
| Dark logos invisible in Tools | Devicon default is dark `#181616` | Use `./assets/icons/github.svg` (included) or `https://cdn.simpleicons.org/<brand>/white`. |
| Gravestones appear on active days | Calendar date alignment mismatch | Make sure your local machine and workflow runner fetch the current year's calendar. Running the generator via GitHub Actions automatically synchronizes with UTC time. |
